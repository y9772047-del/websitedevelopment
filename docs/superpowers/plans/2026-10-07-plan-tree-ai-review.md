# 学习目标树与 AI 复盘实施计划

**目标：** 在学生端展示计划、任务、学习记录的层级和进度，并按计划生成有数据依据的 AI 复盘。

**架构：** 前端复用现有三个列表接口组装只读树。复盘由后端按登录用户重新查询计划、任务和记录，再调用现有 DeepSeek 配置。保持数据库和现有接口不变。

**技术栈：** Vue 3、Vite、Spring Boot、MyBatis-Plus、JUnit、Node test。

## 工作项

- [x] 为树形分组、任务进度和空计划编写前端测试并实现纯函数。
- [x] 在学习计划详情内展示左到右的目标树；任务默认可见，记录按任务独立展开，支持同时展开多个任务；移除独立导航入口。
- [x] 新增目标复盘响应、服务和接口；校验计划归属及最少记录量，限制提示词中的记录数量和文本长度。
- [x] 为目标复盘的归属和数据不足情形添加后端测试。
- [x] 完成前端测试及构建、Maven 测试及打包，并检查改动范围。

## 边界

- 不修改数据库结构、现有 API 路径与响应格式、登录和权限规则。
- AI 复盘按需生成，不持久化；刷新数据后清除旧结果。
- DeepSeek 未配置或失败时明确提示，不把规则文本伪装为 AI 输出。
