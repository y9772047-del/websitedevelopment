# 夜间模式配色优化设计

## 目标

将现有偏紫、偏闷的夜间模式调整为暗蓝灰背景与柔和紫色点缀，在不改变页面结构和业务逻辑的前提下，强化页面、导航、卡片、日历格子和节点列表之间的层级。

## 配色层级

- 页面背景使用深蓝灰，辅以低透明紫色环境光。
- 导航栏比页面略亮，卡片再亮一级，内部列表项使用独立的柔和表面色。
- 紫色仅用于按钮、选中态、标签和重点边框。
- 文字分为标题、正文、次要文字三级，避免灰紫色导致阅读发闷。
- 热力图从低对比蓝灰逐步过渡到柔和紫色，低强度色块保持可辨。

## 定向覆盖

- 首页：统计卡、图表卡、投入图例和热力图。
- 学习日历：星期栏、日期格、空白格、选中态、右侧详情卡及任务标签。
- 重要节点：月份容器、节点列表项、状态标签、编辑和删除按钮。
- 公共区域：页面背景、导航栏、表单控件、模态框和轮廓按钮。

## 边界

只修改 `body.theme-dark` 变量及必要的深色模式选择器；不改 HTML 结构、布局、后端、数据库、接口或业务逻辑。修改后同步更新三个页面的 CSS 缓存版本。

## 验证

新增静态资源回归测试，验证暗蓝灰变量、关键深色选择器和缓存版本；运行目标测试及 Maven `clean package -DskipTests`。
